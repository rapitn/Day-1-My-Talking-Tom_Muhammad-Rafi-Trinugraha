Repository (repo) di GitHub adalah tempat penyimpanan proyek yang berisi semua file, folder, dan riwayat perubahan (versi) dari proyek tersebut, sehingga bisa dikelola, dibagikan, dan dikerjakan bersama orang lain.
---------------------------------------------------
1.Menyimpan kode dan file proyek di satu tempat yang terpusat dan aman (cloud), jadi tidak hilang kalau laptop atau server bermasalah.

2.Mengelola versi (version control). Setiap perubahan tercatat, sehingga kamu bisa melihat riwayatnya atau mengembalikan ke versi sebelumnya kalau ada yang rusak.

3.Kolaborasi tim. Banyak orang bisa mengerjakan proyek yang sama lewat branch, pull request, dan code review tanpa saling menimpa pekerjaan.

4.Backup dan sinkronisasi antar perangkat. Misalnya kode di laptop bisa ditarik ke server homelab dengan git pull.
5.Dokumentasi proyek lewat README, wiki, dan issues, supaya orang lain (atau dirimu sendiri nanti) paham cara memakai dan menjalankan proyek.
6.Pelacakan masalah dan tugas dengan fitur Issues dan Projects.
7.Otomatisasi dengan GitHub Actions, misalnya untuk testing, build, atau deploy otomatis.
8.Portofolio dan berbagi karya. Repo public bisa jadi bukti kemampuanmu atau dibagikan sebagai open source.

Judul dan tema kegiatan
Workshop bertajuk From AI to GitHub: Building with AI, Managing Change with GitHub. Temanya menggabungkan dua hal: membuat dan mengembangkan karya dengan bantuan AI, lalu mengelola perubahan dan kolaborasinya menggunakan GitHub.

Pemateri
Nugi Farhan, Senior Product Designer dengan pengalaman 6 tahun. Ia pernah menjadi UX Advisor untuk program Bangkit, DBS CodingCamp, dan BI Hackathon.

Tujuan pembelajaran
Peserta diharapkan mampu menjelaskan bagaimana prompt AI yang lebih spesifik menghasilkan output yang lebih baik, membedakan Git dan GitHub, mengidentifikasi repository, commit, branch, dan pull request, serta melakukan version control.

Materi prompt engineering
Membahas cara merancang instruksi agar AI memberi jawaban yang tepat dan relevan. Struktur prompt yang baik terdiri dari Role, Task, Context, dan Format, dengan contoh prompt pembuatan Student Task Planner. Manfaatnya: performa model meningkat, bias dan respons yang tidak pantas berkurang, hasil lebih terkontrol dan dapat diprediksi, serta pengalaman pengguna lebih baik.

Materi Git dan GitHub
Git adalah sistem version control terdistribusi untuk melacak perubahan kode secara lokal, sedangkan GitHub adalah platform berbasis web untuk menyimpan repository Git secara online dan berkolaborasi. Materi mencakup alur kerja Git (working directory, staging area, git directory), perintah dasar (git init, git add, git commit, git clone, git remote add, git push, git pull), serta setup Git, VS Code, identitas Git, dan SSH key untuk koneksi ke GitHub.

Praktik dan dokumentasi kegiatan
Peserta membuat aplikasi sederhana Student Task Planner dengan alur: menggunakan platform AI (Claude, Antigravity, atau ChatGPT), menulis prompt, menjalankan git init, commit dan push ke GitHub, melakukan perubahan, lalu commit dan push kembali. Dokumentasi kegiatan ini berupa slide presentasi yang memuat materi, contoh prompt, dan langkah-langkah praktik tersebut.
